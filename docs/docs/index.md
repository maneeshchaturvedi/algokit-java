# AlgoKit Java

**Battle-tested building blocks for coding interviews.**

AlgoKit is a focused collection of algorithm templates and data structures that you can import into your practice environment. Every function is:

- **Self-contained** — no dependencies beyond the JDK
- **Readable** — fits on one screen, with clear names and comments
- **Tested** — every function has tests that double as usage examples

## Who is this for?

Engineers preparing for coding interviews who want to stop rewriting binary search, union-find, and sliding window templates from scratch every time they sit down to practice.

## How to use it

**Option 1: Maven dependency** — add it to your `pom.xml` and import what you need.

**Option 2: Copy what you need** — clone the repo, read the source, copy the functions you want into your own solution files. Every function is designed to be understood, not just called.

## What's included

| Category | Highlights |
|----------|-----------|
| **Arrays & Strings** | Frequency maps, prefix sums, character counting |
| **Binary Search** | The `firstTrue` predicate template — every variant is a one-liner |
| **Sliding Window** | Fixed, longest-valid, shortest-valid, k-distinct |
| **Monotonic Stack** | Next-greater-element, sliding window min/max |
| **Linked Lists** | ListNode, construction helpers, middle node, remove-all |
| **Trees** | All traversals (recursive + iterative), level-order, balance check |
| **Graphs** | BFS, DFS, Dijkstra, topological sort, cycle detection, UnionFind |
| **Intervals** | Merge overlapping intervals |
| **DP** | Coin change, grid paths, deep-recursion helper |
| **Backtracking** | Subsets, combinations |
| **Data Structures** | Versioned key-value store, LRU cache |
| **Text** | Tokenizer, TF-IDF scoring |
